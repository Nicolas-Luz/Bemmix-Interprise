BEMMIX - SITE INSTITUCIONAL
============================

Arquivos:
- index.html
- style.css
- script.js
- assets/bemmix-logo.png

Como usar:
1. Mantenha a estrutura de pastas.
2. Abra index.html no navegador.
3. Para publicar, envie a pasta para seu servidor/hosting.

Observação:
Os dados de empresa, produtos, preços, e-mail e telefone são fictícios, conforme solicitado.
O formulário funciona no front-end e mostra uma confirmação, mas não envia e-mail sem um backend ou serviço de formulário.
